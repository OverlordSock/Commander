# Commander
 A repository containing the source code for the Godot 4 game project titled "Commander"

**Play the game at:**
https://overlordsock.itch.io/commander 

# For marking:
- Download the Godot engine launcher at https://godotengine.org/
- Download the source code for Commander from this repository
- Open the project.godot file in this repo through the Godot import window (see image 1)
- Mark scripts by opening scripts under the scripts folder and viewing scripts under the scripts tab (see image 2)
- Mark scenes (node groups) by opening them under the scenes folder and viewing them under the 2D tab (see image 2)
- For any questions, contact me any time by my student email and I will reply within the day

- The highlighted folders in the bottom left contain the scenes (node groups) and scripts (code) respectively. Double clicking a scene or script will open it in the editor
- The highlighted tab in the top left is the scene tree where you can browse the nodes within a scene
- The "2D" and "Script" tabs highlighted at the top of the UI can be used to switch between view of scenes and view of scripts
